# 🌿 Our Little Escape

**Our Little Escape** is a simple interactive web project created using HTML, CSS, and JavaScript. The project focuses on providing users with a clean, relaxing, and easy-to-use web experience.

## 📌 About the Project

This project was developed to practise front-end web development and demonstrate how HTML, CSS, and JavaScript work together to create an interactive website.

The application includes:
- A structured webpage using HTML
- Custom styling using CSS
- Interactive functionality using JavaScript
- A simple and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling and layout
- **JavaScript** – Interactivity and functionality

## 📂 Project Structure

```text
our-little-escape/
│
├── index.html

├── script.js
└── README.md
```

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. The website will run directly in the browser.
